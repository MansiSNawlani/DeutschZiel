# Build Plan

Generated by `/adopt`. Checked items are already built and working in the app;
unchecked items are what is left. Run `/feature` to spec the next unchecked
item, or `/feature 7` to pick one. Do not renumber completed features, because
their archived specs refer to these IDs.

The scope here is **v0**, the five-week personal study tool from
`docs/adr/0001-v0-v1-split.md`. v1 is deliberately frozen and is listed at the
bottom for reference only.

## Your features

- [x] 1. **Bring-your-own-key settings** - Gemini key in browser storage, runtime model discovery, Wortliste toggle, journal folder selection
- [x] 2. **Schreiben practice loop** - pick or generate a Goethe B1 Teil 1-3 Aufgabe, write it under a timer, submit for Feedback
- [x] 3. **Tiered correction feedback** - criterion bands, Correct / Simpler / More advanced rewrites, and Mistake instances tagged from the closed Error category list
- [x] 4. **Attempt journal on disk** - every Attempt written as Markdown via the File System Access API, with Mistake pattern counts read back across Attempts
- [x] 5. **Draft persistence** - the in-progress Task and text saved on every keystroke, so a reload cannot cost a timed Aufgabe
- [x] 6. **Sprechen Teil 2** - the five-Folie presentation, recorded in the browser and assessed from the audio

- [ ] 8. **Real Schreiben tasks from the official papers** - replace the placeholder seed Tasks with ones derived from the Übungssatz, holding the Modellsatz back for cold timed mocks
- [ ] 9. **Verify the scoring against the official Bewertungskriterien** - confirm the 0-3 criterion bands, the Folien wording, and the task timings and word targets against the published papers
- [ ] 10. **Mistake pattern view** - a screen that shows which Error categories actually recur across Attempts, and their trend, rather than only the counts shown after a single Attempt
- [ ] 11. **Re-decide the six-hour cap** - after a week of real use, extend the tool or stop, based on whether it is being reached for unprompted
- [ ] 12. **Attempt history in the app** - browse past Attempts, reopen any one's Feedback, and compare a first and a later Attempt on the same Task

> Item 12 is a reading surface, not new storage. `journal.ts` already writes
> every Attempt to disk as Markdown, including the full Feedback; nothing in the
> app ever reads it back, so the only way to review past Feedback today is to
> open the files by hand. It shares its data source with item 10, so the two are
> worth specing together or back to back.

## Frozen: v1, after the exam

Not to be built now. ADR 0001 freezes all of this until after the exam, and the
full detail lives in `project-list.md`. Listed only so the shape is visible.

- Phase 1 - Tutor plus textbook: auth, PDF upload, chunking, Postgres with
  pgvector, RAG, the tutor interface, and the Expo shell on iOS, Android and web
- Phase 2a - Practice: Lesen and Schreiben, question generation, answer
  evaluation, level-aware explanations
- Phase 2b - Practice: Hören and Sprechen, including the audio infrastructure
  and the platform-specific recording layer
- Phase 3 - Exam training: timed exercises, section tests, mock exams, mistake
  history, progress dashboard
- Phase 4 - Adaptive tutor: per-skill ability estimation, weak-topic detection,
  adaptive difficulty, readiness score
- Phase 5 - Expansion: telc B1, Goethe B2 and telc B2 as additional exam configs
